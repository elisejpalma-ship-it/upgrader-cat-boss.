# Upgrader Cat Boss — Android-проект

Это исходный проект Android-приложения, которое открывает мобильную игру Upgrader в WebView. В комплект включены HTML-игра и логотип.

## Как получить APK
1. Установи Android Studio на компьютер.
2. Открой в Android Studio папку `UpgraderAndroid`.
3. Дождись завершения Gradle Sync и установки Android SDK 35, если Android Studio попросит.
4. Выбери **Build → Build APK(s)**.
5. APK обычно появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

Для сборки нужен интернет, чтобы Android Studio скачала Gradle и плагины. В текущей среде нет Android SDK/Gradle, поэтому здесь подготовлен проект, но сам APK не скомпилирован.

Игра демонстрационная: баланс и цены — игровые, реальных платежей нет.
